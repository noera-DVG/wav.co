# 🚀 Quick Start Guide

## One-Click Installation (Easiest)

1. **Download** [`WAV.co-v1.0.0.zip`](https://github.com/noera-DVG/wav.co/releases/download/v1.0.0/WAV.co-v1.0.0.zip)
2. **Extract** the ZIP file (double-click on macOS)
3. **Move** `WAV.co.app` to your Applications folder
4. **Open** and start producing!

> 💡 **Don't see it in App Store?** It's not there yet, but this is the official release!

---

## ⚙️ Installation Details

### macOS (Recommended)

1. Visit the [Releases Page](https://github.com/noera-DVG/wav.co/releases)
2. Download **WAV.co-v1.0.0.zip**
3. Double-click the ZIP to extract
4. Drag `WAV.co.app` to Applications

**First-time warning?**
- Right-click `WAV.co.app` → **Open** → Click **Open**

### Windows (Coming Soon)

Tauri support for Windows is ready. Stay tuned!

## 🎹 Ableton Live Integration

### Quick Setup

1. **Copy** `wavco_bridge.py` from [src-tauri/resources/bridge/](https://github.com/noera-DVG/wav.co/tree/main/src-tauri/resources/bridge)
2. **Place** it in `~/Music/Ableton/User Library/Remote Scripts/WAV.co/`
3. **Restart** Ableton and select WAV.co in Control Surfaces

**Detailed instructions:** See [INSTALLATION.md](./INSTALLATION.md)
